隐私政策

WenPo 在 Mac 上完成排盘。AI 解读是可选功能，由你选择的第三方服务提供。

更新日期：2026 年 9 月 18 日

1. 本地排盘

六爻排盘在你的 Mac 上运行。仅使用排盘功能时，问卜事由、起卦时间与爻值不会发送到 WenPo 开发者的服务器。WenPo 不提供开发者运营的数据中转服务器、用户账户、广告或行为分析服务。

2. AI 解读与第三方服务

如果你选择使用 AI 解读，WenPo 会直接连接你在设置中选择的 OpenAI、Gemini、DeepSeek，或你自行填写的 HTTPS API 地址。首次向每个服务地址发送卦盘数据前，应用会请求你的许可。

发送内容包括问卜事由、卦盘与用神信息，以及所选提示词。追问时，还会发送当前卦盘、本次解读摘要和对话记录。启用“新盘完成后自动分析”后，符合条件的新盘会自动发送相关信息，并可能消耗你在该服务的额度。

第三方服务可能按其隐私政策和你的账户设置保存、处理这些数据。使用前请阅读你所选服务商的隐私政策。WenPo 无法替第三方服务管理已收到的数据。

AI 解读不是排盘的必要条件。你可以关闭自动分析，也可以在应用设置中撤销对当前服务地址的发送许可。

3. 本机保存的信息

AI 服务地址、模型、提示词、自动分析选项、发送许可和你输入的 API Token 保存在本机应用设置中。当前版本的 API Token 保存在 macOS 的 UserDefaults 中。

AI 解读结果与追问记录仅保留在当前运行会话的内存中；关闭应用后，WenPo 不会另行保存这些记录。

4. 截图与剪贴板

你主动保存的卦盘截图会写入你选择的文件夹。你主动复制的卦盘数据会进入系统剪贴板；如果剪贴板内容未被其他操作替换，应用会在约 30 秒后尝试清除。若应用在此之前关闭，则无法继续执行清除操作。

5. 你的选择与数据删除

你可以在应用设置中修改或删除 API Token、关闭自动分析，并撤销对当前 AI 服务地址的发送许可。卸载应用不一定会删除 macOS 留存的应用偏好设置；如需清除，可删除 WenPo 的本地偏好设置。

若要查询或删除第三方 AI 服务已收到的数据，请按相应服务商的政策直接联系该服务商。

6. 联系我们

如对本政策或 WenPo 的数据处理有疑问，请发送邮件至 chiuyan.ning@gmail.com。

本政策如有更新，会在此页面公布更新后的内容及日期。
