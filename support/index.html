常见问题

不连接 AI，也能排盘吗？

可以。排盘在本机完成；AI 解读是可选功能。

AI 解读如何使用？

在“WenPo → 设置 → AI 服务”中选择服务、填写你自己的 API Token、测试连接并选择模型。首次发送卦盘数据前，应用会显示数据发送说明并征求许可。

AI 连接失败怎么办？

请检查 API 地址是否以 https:// 开头、Token 是否有效、模型是否可用，以及相应服务账户是否还有额度。若仍失败，请附上错误提示联系我们，但不要发送 Token。

如何保存卦盘？

排盘后，在 WenPo 菜单中选择“保存卦盘截图”，再选取保存文件夹。也可以选择“保存卦盘数据”，将文本复制到剪贴板。
